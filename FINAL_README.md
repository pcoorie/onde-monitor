# Onde Monitor Project

## About

This is the Onde Monitor project - a Python-based automation tool for monitoring tasks with Firefox browser integration and keychain management capabilities.

## Repository Overview

To complete this setup, I've created all necessary files in the repository structure. The following are the key components:

### Files
- `onde_monitor.py` - Main Python monitor script  
- `onde_monitor_firefox.py` - Firefox automation scripts
- `onde_monitor_keychain.py` - Keychain operations functions
- `run_onde_monitor_firefox.sh` - Bash script for Firefox automation
- `setup_keychain.sh` - Bash script to set up keychain
- `run_onde_monitor.applescript` - macOS AppleScript for monitor run
- `run_onde_monitor_firefox.applescript` - macOS AppleScript for Firefox monitor

### Scripts
The project includes both Python and shell scripts that work together:

1. **Python scripts** (main functionality)
2. **Shell scripts** (for execution and setup)
3. **AppleScript files** (macOS automation interface)

### Usage
To use this project:
1. Clone the repository to your local machine
2. Review the README.md and related documentation
3. Make necessary scripts executable with `chmod +x`
4. Configure environment variables as needed
